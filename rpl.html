Tentang RPL

Pengertian

Rekayasa Perangkat Lunak (RPL) adalah satu bidang profesi yang mendalami cara-cara pengembangan perangkat lunak termasuk pembuatan, pemeliharaan, manajemen organisasi pengembanganan perangkat lunak dan manajemen kualitas.

  • Web Programming (HTML, CSS, JS)
  • Database Management
  • Framework Development
  • Mobile App Development
